# 🏥 NURSE 30: The Detective

> A clinical + emotional transition simulator for new nurses and IEN.

**"Helping new nurses survive emotionally and clinically in real hospital environments."**

---

## 🎮 Play Now

Open `nurse30_detective.html` in any modern browser — no installation required.

---

## 📋 What is this?

NURSE 30 is a 30-day interactive clinical simulation game designed for:
- **New RN graduates** entering the hospital environment
- **Internationally Educated Nurses (IEN)** adapting to North American practice

Each day is a shift. Each shift is a case. You find clues, make decisions, and grow.

---

| Level | Days | Theme |

## 🔧 Features

- **30-day calendar** with unlock progression
- **SBAR drag-and-drop** (Level 1–5, unlimited retries)
- **V/S monitor + IV panel + Lab Results** — separate panels, real-time updates
- **Fail-Fast system** — wrong answers get immediate clinical explanation
- **Locker room ending animation** — 2D canvas, encouragement messages
- **Visual patient deterioration** — skin color, mottling, confusion state
- **Code Blue** system (Day 2)
- **Sound engine** (21 SFX)
- **LocalStorage save** — progress persists across sessions
